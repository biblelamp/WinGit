Privacy policy

Last updated: 22 November 2026

WinGit does not collect, store or share any personal data. It has no user accounts, no analytics, no advertising and no telemetry. This policy applies to the WinGit desktop application, however it was installed (Microsoft Store, installer, portable archive or Linux package), and to this website.

Data on your computer

WinGit keeps its settings in a local file: the list of repositories you added, the last opened repository and file, the window size and layout, the language and the theme. On Windows the file is in %APPDATA%\WinGit (for the Microsoft Store version Windows keeps it in the app's private folder), on Linux in ~/.wingit. The file never leaves your computer, and uninstalling the app removes or leaves it according to the installation type; you can delete it at any time.

Your repositories, their files and their history stay where they are. WinGit reads and changes them only when you work with them.

Network

WinGit does not transfer any information to other networked systems unless you ask for it. The only connections it makes are to the Git remote repositories that you set up: when you clone, fetch, pull or push, and when it fetches those remotes in the background to show new commits. What is sent is what Git itself sends to the server you chose; the server's own privacy policy applies.

Links in the program (for example in the About dialog) open in your web browser only when you click them.

Passwords and keys

WinGit never stores passwords, tokens or SSH keys. Sign-in to remote repositories is handled by your installed Git and its helpers, such as Git Credential Manager (HTTPS) or OpenSSH and Pageant (SSH), under their own privacy policies.

Microsoft Store

When you get WinGit from the Microsoft Store, Microsoft handles the download, installation and updates under the Microsoft Privacy Statement. Microsoft may give the developer aggregated statistics such as the number of installations and crash reports from Windows; they identify no person and contain no repository content.

This website

The website uses no cookies and no analytics. It asks the GitHub API for the latest release to show the download links; downloads are served by GitHub under its privacy statement. The site is hosted on GitHub Pages, which may log visitors' IP addresses for security. The footer badge image is loaded from opensourcealternatives.to, a directory that lists WinGit.

Changes and contact

If this policy changes, the new version is published on this page with a new date. Questions: open an issue at github.com/biblelamp/WinGit/issues.
