Политика конфиденциальности

Обновлено: 22 ноября 2026 г.

WinGit не собирает, не хранит и не передаёт никакие персональные данные. В программе нет учётных записей, аналитики, рекламы и телеметрии. Эта политика относится к настольной программе WinGit, как бы она ни была установлена (Microsoft Store, установщик, портативный архив или пакет для Linux), и к этому сайту.

Данные на вашем компьютере

Настройки WinGit хранятся в локальном файле: список добавленных репозиториев, последний открытый репозиторий и файл, размер и расположение окна, язык и тема. В Windows файл лежит в %APPDATA%\WinGit (у версии из Microsoft Store Windows хранит его в личной папке приложения), в Linux — в ~/.wingit. Файл никуда не отправляется; при удалении программы он удаляется или остаётся в зависимости от способа установки, и его можно удалить в любой момент.

Ваши репозитории, их файлы и история остаются на своих местах. WinGit читает и меняет их только тогда, когда вы с ними работаете.

Сеть

WinGit не передаёт никакую информацию в другие сетевые системы, если вы об этом не попросили. Программа подключается только к удалённым Git-репозиториям, которые настроили вы: при clone, fetch, pull и push, а также при фоновом fetch этих репозиториев, чтобы показать новые коммиты. Передаётся то же, что передаёт сам Git на выбранный вами сервер; для сервера действует его собственная политика конфиденциальности.

Ссылки в программе (например, в окне «О программе») открываются в браузере только по вашему щелчку.

Пароли и ключи

WinGit никогда не хранит пароли, токены и SSH-ключи. Вход в удалённые репозитории выполняют установленный у вас Git и его помощники — Git Credential Manager (HTTPS) или OpenSSH и Pageant (SSH) — по своим политикам конфиденциальности.

Microsoft Store

Если вы установили WinGit из Microsoft Store, загрузкой, установкой и обновлениями занимается Microsoft согласно Заявлению о конфиденциальности Microsoft. Microsoft может предоставлять разработчику обобщённую статистику — например, число установок и отчёты Windows о сбоях; по ним нельзя определить человека, и в них нет содержимого репозиториев.

Этот сайт

Сайт не использует cookie и аналитику. Он запрашивает у GitHub API последний релиз, чтобы показать ссылки на скачивание; файлы раздаёт GitHub согласно своему заявлению о конфиденциальности. Сайт размещён на GitHub Pages, которые могут записывать IP-адреса посетителей в целях безопасности. Значок в подвале загружается с opensourcealternatives.to — каталога, в котором есть WinGit.

Изменения и связь

Если политика изменится, новая версия будет опубликована на этой странице с новой датой. Вопросы можно задать в github.com/biblelamp/WinGit/issues.
