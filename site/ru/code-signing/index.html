Политика подписи кода

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Бесплатную подпись кода предоставляет SignPath.io, сертификат выдан SignPath Foundation. Им подписаны установщик для Windows (MSI) и файл запуска программы WinGit.exe — в установщике и в переносном ZIP. Windows показывает издателем SignPath Foundation.

Что подписывается

Только файлы, собранные GitHub Actions из открытого исходного кода в github.com/biblelamp/WinGit процессом выпуска этого репозитория. Файлы, собранные где-либо ещё, не подписываются. Пакеты для Linux этим сертификатом не подписываются.

Роли в команде

  • Авторы и рецензенты: biblelamp (владелец проекта). Изменения других участников проверяются перед слиянием.
  • Подтверждающие подпись: biblelamp. Каждый запрос на подпись релиза подтверждается вручную.

Конфиденциальность

Программа не передаёт никакую информацию в другие сетевые системы, если об этом явно не попросил пользователь или тот, кто её устанавливает или использует.

WinGit подключается только к удалённым Git-репозиториям, которые настроили вы (clone, fetch, pull, push и фоновый fetch этих репозиториев). Программа работает через установленный у вас Git, который может запрашивать учётные данные у Git Credential Manager или SSH — для них действуют их собственные политики конфиденциальности. WinGit не хранит пароли и не отправляет статистику использования.

Этот сайт запрашивает у GitHub API последний релиз, чтобы показать ссылки на скачивание; файлы раздаёт GitHub согласно своему заявлению о конфиденциальности. Значок в подвале загружается с opensourcealternatives.to — каталога, в котором есть WinGit.
