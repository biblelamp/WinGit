Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

The Windows installer (MSI) and the program launcher WinGit.exe, in the installer and in the portable ZIP, are signed with this certificate. Windows shows SignPath Foundation as the publisher.

What gets signed

Only files built by GitHub Actions from the public source code at github.com/biblelamp/WinGit, by the release workflow of that repository. Files built anywhere else are never signed. Linux packages are not signed with this certificate.

Team roles

  • Committers and reviewers: biblelamp (project owner). Changes from other contributors are reviewed before they are merged.
  • Approvers: biblelamp. Every signing request for a release is approved manually.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

WinGit connects only to the Git remote repositories that you set up (clone, fetch, pull, push, and the background fetch of those remotes). It works through your installed Git, which may ask Git Credential Manager or SSH for credentials; their own privacy policies apply. WinGit does not store passwords and sends no usage statistics.

This website asks the GitHub API for the latest release to show the download links; downloads are served by GitHub under its privacy statement. The footer badge image is loaded from opensourcealternatives.to, a directory that lists WinGit.
