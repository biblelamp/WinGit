Zásady ochrany soukromí

Poslední aktualizace: 22. listopadu 2026

WinGit neshromažďuje, neukládá ani nesdílí žádné osobní údaje. Nemá uživatelské účty, analytiku, reklamu ani telemetrii. Tyto zásady platí pro desktopovou aplikaci WinGit bez ohledu na způsob instalace (Microsoft Store, instalátor, přenosný archiv nebo balíček pro Linux) a pro tento web.

Data ve vašem počítači

WinGit ukládá nastavení do místního souboru: seznam přidaných repozitářů, naposledy otevřený repozitář a soubor, velikost a rozložení okna, jazyk a motiv. Ve Windows je soubor v %APPDATA%\WinGit (u verze z Microsoft Store jej Windows ukládá do soukromé složky aplikace), v Linuxu v ~/.wingit. Soubor nikdy neopouští váš počítač; při odinstalaci se podle způsobu instalace smaže nebo zůstane a můžete jej kdykoli smazat.

Vaše repozitáře, jejich soubory a historie zůstávají tam, kde jsou. WinGit je čte a mění jen tehdy, když s nimi pracujete.

Síť

WinGit nepředává žádné informace jiným síťovým systémům, pokud o to nepožádáte. Připojuje se pouze ke vzdáleným Git repozitářům, které jste nastavili: při clone, fetch, pull a push a při fetch těchto repozitářů na pozadí, aby ukázal nové commity. Odesílá se totéž, co posílá samotný Git na vámi zvolený server; pro server platí jeho vlastní zásady ochrany soukromí.

Odkazy v programu (například v okně O aplikaci) se otevřou v prohlížeči jen po vašem kliknutí.

Hesla a klíče

WinGit nikdy neukládá hesla, tokeny ani SSH klíče. Přihlášení ke vzdáleným repozitářům zajišťuje váš nainstalovaný Git a jeho pomocníci, jako Git Credential Manager (HTTPS) nebo OpenSSH a Pageant (SSH), podle svých vlastních zásad ochrany soukromí.

Microsoft Store

Pokud WinGit získáte z Microsoft Store, stažení, instalaci a aktualizace zajišťuje Microsoft podle Prohlášení společnosti Microsoft o zásadách ochrany osobních údajů. Microsoft může vývojáři poskytovat souhrnné statistiky, například počet instalací a hlášení Windows o chybách; neidentifikují žádnou osobu a neobsahují obsah repozitářů.

Tento web

Web nepoužívá cookies ani analytiku. Ptá se GitHub API na poslední vydání, aby zobrazil odkazy ke stažení; soubory poskytuje GitHub podle svého prohlášení o ochraně soukromí. Web běží na GitHub Pages, které mohou z bezpečnostních důvodů zaznamenávat IP adresy návštěvníků. Odznak v zápatí se načítá z opensourcealternatives.to, katalogu, ve kterém je WinGit uveden.

Změny a kontakt

Pokud se zásady změní, nová verze bude zveřejněna na této stránce s novým datem. Dotazy: založte issue na github.com/biblelamp/WinGit/issues.
