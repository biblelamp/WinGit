Zásady podepisování kódu

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Bezplatné podepisování kódu poskytuje SignPath.io, certifikát vydala SignPath Foundation. Je jím podepsán instalátor pro Windows (MSI) a spouštěcí soubor programu WinGit.exe — v instalátoru i v přenosném ZIP. Windows jako vydavatele zobrazí SignPath Foundation.

Co se podepisuje

Pouze soubory sestavené službou GitHub Actions z veřejného zdrojového kódu v github.com/biblelamp/WinGit procesem vydání tohoto repozitáře. Soubory sestavené jinde se nepodepisují. Balíčky pro Linux se tímto certifikátem nepodepisují.

Role v týmu

  • Autoři a recenzenti: biblelamp (vlastník projektu). Změny ostatních přispěvatelů se před sloučením kontrolují.
  • Schvalovatelé: biblelamp. Každý požadavek na podpis vydání se schvaluje ručně.

Ochrana soukromí

Program nepředává žádné informace jiným síťovým systémům, pokud o to výslovně nepožádá uživatel nebo ten, kdo program instaluje či používá.

WinGit se připojuje pouze ke vzdáleným Git repozitářům, které nastavíte vy (clone, fetch, pull, push a fetch těchto repozitářů na pozadí). Program pracuje přes váš nainstalovaný Git, který může žádat o přihlašovací údaje Git Credential Manager nebo SSH — pro ty platí jejich vlastní zásady ochrany soukromí. WinGit neukládá hesla a neodesílá statistiky používání.

Tento web se ptá GitHub API na poslední vydání, aby zobrazil odkazy ke stažení; soubory poskytuje GitHub podle svého prohlášení o ochraně soukromí. Odznak v zápatí se načítá z opensourcealternatives.to, katalogu, ve kterém je WinGit uveden.
